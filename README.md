# Worst UX Alarm

A one-day design challenge: build an alarm clock with intentionally the worst dismissal UX.

Instead of the classic dismiss/snooze, the user has to complete four randomised cognitive tasks to turn the alarm off:
1. Find the right button among 12 lookalikes (Hick's Law)
2. Type the shown word backwards (Cognitive Load)
3. Stroop test - name the color, not the word (Cognitive Load)
4. Hold a button for exactly 5 seconds, ±0.5s tolerance (Competence)

**Live demo:** https://worst-alarm.vercel.app
**Case study:** https://worst-alarm.vercel.app/case

## Concept

Deliberately breaks core UX laws to explore why they matter through hostile design.
